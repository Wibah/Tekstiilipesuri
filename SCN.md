## Linkitysperiaatteet

- **Ylös:** jokainen tukisivu linkittää leipätekstissä emopilariinsa (Kärcherin mallisivut, varaosat ja vianetsintä Kärcher-hubiin, SpotClean Pro Bissell-hubiin, merkkisivut, oppaat ja käyttökohteet etusivulle). Murupolku ei riitä yksinään.
- **Alas:** etusivu linkittää kaikkiin tukisivuihinsa ja merkkisivuihin, Kärcher-hub kaikkiin Kärcherin mallisivuihin, varaosiin ja vianetsintään, ja Bissell-hub SpotClean Prohon.
- **Sivuttain:** käyttökohdesivut (sohva, auto, matto, akku) linkittävät toisiinsa ja sopiviin mallisivuihin, merkkisivut vertailumalleihin (Kärcher SE 3, SE 2, Bissell) ja Kärcher-hub muihin merkkisivuihin. Varaosat ja vianetsintä linkittävät toisiinsa.
- **Ankkurit** kuvaavat kohdetta ("maton pesu -oppaassa", "Kärcher-tekstiilipesurien vertailussa"), eivät "lue lisää".
- **Tarkistus:** `npm run build && npm run scn:linkit` kokoaa alla olevan linkkikartan ja ilmoittaa rikkinäiset linkit, orposivut ja puuttuvat linkit emopilariin. Auditoitu 2026-10-12: ei virheitä.
